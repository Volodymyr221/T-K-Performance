# /onovy — передати стан у новий чат

**Коли:** контекст ~70%+ (хук попередить), сесія закінчується, пересідаєш на інший акаунт.

🛑 **Не плутати з `/finish`.** `/finish` **публікує** роботу в `main`.
`/onovy` **передає контекст** — код може бути ще недороблений.

Мета: **після команди в репозиторії немає нічого, чого не побачить наступний чат.**
Новий чат із чистим пульсом коштує ≈6K токенів на вхід; переповнений — сотні тисяч
на кожен крок.

1. `date && git branch --show-current && git fetch origin -q && git status --short`
2. **Дописати журнал** `_session-log/vova-<дата>.md` — усе значуще, що ще не записано:
   що · навіщо · **що НЕ спрацювало** · слова Вови дослівно · номер PR.
3. **Пульс `NOW.md`:** `node scripts/now_update.mjs` (авто-блок з git), потім
   РУКАМИ переписати прозу: 🎯 ЗАРАЗ · 🔴 ЩО НЕ ГОТОВЕ · 🪤 ПАСТКИ · 🛑 НЕ ЧІПАТИ.
   Жодної заглушки. Тримати **≤200 рядків / 16 KB** — старе в журнал, не сюди.
4. **Перевірка:** `node tests/docs-fresh.mjs`. Червоне — **стискати, не піднімати стелю**.
5. **Коміт + пуш** у робочу гілку. Потім ще раз `node scripts/now_update.mjs` →
   коміт → пуш (щоб авто-блок бачив останній коміт).
6. **Звіт коротко:** що передано, що лишилось недоробленим, перша дія нового чату
   (`/startuem`).
