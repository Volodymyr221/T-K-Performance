1. **Підпиши коміти Вовою:**
   ```
   git config user.name "Вова"
   git config user.email "vitocorleone191@outlook.com"
   ```
   ⚠️ **«Unverified» на GitHub — очікувано, ІГНОРУЙ.** Косметика; пуш і PR не блокує.

2. **Свіжий стан — з `origin`, не з диска:**
   ```
   git fetch origin
   git log --oneline origin/main -10
   git log --oneline HEAD ^origin/main     # має бути порожньо
   ```
   🔴 Локальна папка може стояти на старій гілці — документація виглядатиме
   свіжою, а буде вчорашня.

3. **Гілка:** сесія стартує на авто-гілці `claude/...` — на ній і працюй.
   У `main` напряму не пушимо (виняток — дрібні коміти в документацію).

4. **Заведи журнал сесії:** `_session-log/vova-<РРРР-ММ-ДД>.md` у корені.
   Дописуй **по ходу** після кожної значущої дії: файл · навіщо · що не спрацювало ·
   слова Вови дослівно. **Комітируй і пуш кожні кілька кроків**, не наприкінці.
