# Заявки з форми → Telegram

## Чому не напряму

Сайт лежить на **GitHub Pages** — це просто статичні файли, сервера немає.
Щоб надіслати повідомлення в Telegram, потрібен **токен бота**. Якщо покласти
токен у код сайту, його прочитає будь-хто: увесь JavaScript видно у браузері,
а репозиторій ще й публічний. Бота одразу вкрадуть.

Тому між сайтом і Telegram стоїть **Cloudflare Worker** — крихітний сервер,
безкоштовний до 100 000 запитів на день. Токен зберігається в його секретах.
Сайт шле заявку воркеру, воркер шле її в Telegram.

```
браузер ──POST JSON──> Cloudflare Worker ──токен──> Telegram
 (нічого не знає)        (знає токен)                 (чат Вови)
```

## 🟢 Поки воркера немає — форма шле через WhatsApp

`formEndpoint` у `assets/js/config.js` порожній → форма складає заявку в
текст і відкриває **WhatsApp клієнта** з уже набраним повідомленням. Сервер
не потрібен: шле сам клієнт зі свого застосунку.

🔴 **Межа, через яку воркер усе одно потрібен:** якщо людина не натисне
«надіслати» **вже у WhatsApp** — заявка не дійде, і ми про це не дізнаємось.
Воркер — єдиний шлях із гарантією доставки.

Поставив тут адресу воркера → форма **сама** перемикається на нього, і підпис
кнопки змінюється з «Send via WhatsApp» на «Send request». Коду не писати.

## Налаштування — 6 кроків

### 1. Створити бота
У Telegram напиши **@BotFather** → `/newbot` → назва → отримаєш **токен**
виду `1234567890:AA...`.

🛑 **Токен = пароль від бота.** Хто його має — читає ВСІ заявки й пише від
імені бізнесу. Не показувати нікому, у git не класти, у чати не надсилати.
🔴 **Якщо токен десь засвітився** — `/revoke` у @BotFather. Старий помирає
миттєво, бот і його імʼя лишаються. Це 30 секунд, робити одразу.

⚠️ **Бота не можна передати іншому акаунту.** Хто створив — той власник
назавжди. Тому створює ВЛАСНИК бізнесу, а не підрядник.

### 2. Дізнатись id чату
Напиши своєму боту будь-що, потім відкрий у браузері:

```
https://api.telegram.org/bot<ТОКЕН>/getUpdates
```

Знайди `"chat":{"id":123456789` — це і є **chat id**.

🛑 У цій адресі **видно токен**. Відкривати тільки у себе в браузері, не
надсилати нікому, після використання закрити вкладку й почистити історію.

> Щоб заявки падали в групу — додай бота в групу, напиши там повідомлення
> і візьми id групи (він відʼємний, напр. `-1001234567890`).

### 3. Створити воркер
[dash.cloudflare.com](https://dash.cloudflare.com) → **Workers & Pages** →
**Create** → **Worker** → назва `tk-form` → **Deploy**.

### 4. Вставити код
**Edit code** → стерти вміст → вставити весь `telegram-worker.js` → **Deploy**.

### 5. Додати секрети
Налаштування воркера → **Variables and Secrets** → **Add** (тип *Secret*):

| імʼя | значення |
|---|---|
| `TELEGRAM_TOKEN` | токен із кроку 1 |
| `TELEGRAM_CHAT` | id із кроку 2 |
| `ALLOWED_ORIGIN` | `https://tk-performance.co.uk` (без шляху після домену) |

`ALLOWED_ORIGIN` — щоб форму не смикали з чужих сайтів.

### 6. Підключити до сайту
Скопіювати адресу воркера (`https://tk-form.<акаунт>.workers.dev`) і вписати
її в `assets/js/config.js`:

```js
formEndpoint: "https://tk-form.<акаунт>.workers.dev",
```

Коміт → push. Форма запрацює.

## Перевірка

```bash
curl -X POST https://tk-form.<акаунт>.workers.dev \
  -H "Content-Type: application/json" \
  -H "Origin: https://tk-performance.co.uk" \
  -d '{"name":"Тест","phone":"07700900000","reg":"AB12 CDE","service":"Diagnostics"}'
```

Очікувано: `{"ok":true}` і повідомлення в Telegram.

## Що воркер уже вміє

- **Пастка для ботів** — приховане поле `website`: заповнене = тихо ігнорується.
- **Обмеження частоти** — 5 заявок за хвилину з однієї IP-адреси.
- **Перевірка даних** — імʼя від 2 символів, телефон від 9 цифр.
- **Чистка тексту** — символи `< > &` прибираються, довжина обрізається.
- **Перевірка джерела** — приймає лише з `ALLOWED_ORIGIN`.
