### 🔴 Обмеження щодо даних і тверджень

1. **Приріст Stage (+15–20% / +25–35%) у ролик НЕ потрапляє.** Ці цифри
   поставив Claude як галузевий орієнтир, замовник їх не підтверджував
   (`NOW.md`, ризик 2). У платній рекламі британського бізнесу непідтверджена
   цифра — це не дрібниця. Через це з роздачі прибрано картку Stage-тюнінгу:
   на знімку сторінки видно «typically +15–20%».
   ➡️ Підтвердить власник — картку можна повернути однією строчкою в `CARDS`.
2. **Номерні знаки на фото** замазані пікселізацією ще на сайті. Через DVLA
   знак виводить на власника — це персональні дані. Використані фото перевірені.
3. **Відгуків у ролику немає.** Вони справжні й публічні, але цитувати людей
   у платній рекламі без їхнього відома — зайвий ризик.

## Етап 1 — візуальний напрямок

**Мова ролика виросла з самого сайту, а не з окремої «рекламної шкурки».**
Токени витягнуті з `assets/css/style.css` і `assets/css/fonts.css`, лежать
у `src/tokens.ts`:

* кольори — `--bg #08080a`, `--surface #131317`, BMW M (`--m-lblue`,
  `--m-blue`, `--m-red`), `--red-txt #ff3355` для дрібного тексту;
* шрифти — **ті самі файли**, що й на сайті: Archivo (800) і JetBrains Mono (500),
  не «схожі», а ті самі `woff2`;
* радіус `--r:14px`, крива `--ease: cubic-bezier(.22,.7,.2,1)`.

**Характер руху.** Вісь енергії — висока (потужність, Stage), вісь тону —
серйозна (інженерія, гроші клієнта). Базовий пресет «активний сміливий»
(~18 кадрів, `bezier(.16,1,.3,1)`), але **переліт прибрано з 1.12 до 1.06**:
1.12 читається як мультик, а тут механіка.

Styleframe окремо не малювався: у проєкту є жорсткий готовий дизайн-регламент
(сам сайт), і набір дозволяє пропустити цей етап із записаною причиною.

## Відхилення від рецептів — свідомі, з причинами

Набір дозволяє відступати від своїх правил, але вимагає кожен відступ записати.

1. **S1: сцена — реальне фото цеху, а не знімок сторінки.**
   Рецепт побудований на знімку вебсторінки. Тут продукт — майстерня, а не
   інтерфейс; фото розібраного двигуна переконує більше за будь-який скриншот.

2. **S1: головний герой — зібрана картка, а не знімок картки з сайту.**
   🔴 Правило Q11: текст, який глядач має прочитати, не менший за 5.2% висоти
   кадру (для 1920 це 100px). На знімку картки сайту заголовок дає **33px** —
   це заборонений «середній стан»: прочитати хочеться, а не видно. Щоб вийти
   на 100px, картку довелося б показати вп'ятеро ширшою за кадр.
   Тому текст, який читають, набрано **токенами сайту** (слово в слово з
   `layout.json`), а знімки сторінки працюють там, де вони — **текстура**.

3. **S2: карток 6, а не 26.**
   Рецепт каже «краще більше» заради відчуття потоку. Але вигадувати послуги,
   яких сервіс не надає, не можна. Потік тримаємо прискоренням роздачі,
   не кількістю. Сьома картка (Stage) прибрана через непідтверджений приріст.

4. **S2: передісторія колоди — не orbit навколо стосу, а попередній кадр.**
   Рецепт вимагає пояснити, «звідки взялася колода». Тут колода лежить там,
   де щойно стояв герой S1, і біла склейка їх зшиває.

5. **S3: побуквенно заїжджає АДРЕСА САЙТУ, а не назва бренду.**
   У рецепті стрічка з назвою. Тут у бренду вже є готовий фірмовий знак
   картинкою, а єдине, заради чого ролик знімали, — адреса сайту. Увага
   віддана їй.

6. **Незалежну перевірку окремим агентом НЕ запускав.**
   Етап 7 набору вимагає третейського субагента з чистим контекстом.
   `CLAUDE.md` цього проєкту прямо забороняє субагентів без явного прохання
   Вови (економія токенів). Самоперевірку зробив сам — вона нижче, і вона
   слабша за третейську. ➡️ Скаже Вова — запущу.

## Самоперевірка за `aesthetic-rules.md`

| пункт | стан | де дивитись |
|---|---|---|
| **R1** ключове стоїть ≥1 с | ✓ | S1 тиша 116–146 (30 кадрів); фінал 419–450 (31 кадр) |
| **R2** швидкість через прискорення, нерухомість у кінці | ✓ | інтервал роздачі 11→4.2 кадру; смуга завмирає з 84-го кадру S2 |
| **R3** головна дуга ≥3 с | ✓ (рівно на межі) | S1 LOCK 26 → LAND 116 = 90 кадрів |
| **R4** ударів на весь кадр ≤3 | ✓ | рівно **один** — на склейці S2→S3 |
| **Q1** реальні знімки сторінки | ✓ | 6 карток із `scripts/capture.cjs`, 4x текстура |
| **Q2** різкість тексту | ✓ | текстури 4x від 540 CSS px; збільшення через CSS `zoom`, не `transform:scale` |
| **Q3** камера без тремтіння | ✓ | дрижання немає ніде; після наїзду камера S1 мертва |
| **Q4** світлові ефекти тільки героєві | ✓ | два кола по контуру — лише картці S1 |
| **Q5** один герой на відкритті | ✓ | одна картка, повна дуга |
| **Q8** фінал — спільне фото на піку | ✓ | 4 роботи з чотирьох боків + знак |
| **Q9** приліт у реальні гнізда | ✓ | гнізда смуги намальовані ДО роздачі |
| **Q11** розмір тексту | ✓ | підписи 92–132px (≥5.2% від 1920), допоміжні 58–76px (≥3%) |
| **S1** звук «як у рекламі продукту» | ✓ | whoosh / impact / sparkle, без ігрових тембрів |
| **S2** таблиця звуку з прив'язкою | ✓ | `SFX` у `src/shots.ts`, кожен рядок — вираз від `SHOTS` |
| **C2** конкретні назви послуг | ✓ | Engines · Diagnostics · Servicing · MOT |
| **P4** одна манера — один раз | ✓ | прожектор / роздача / зліт — кожна по разу |

🔴 **Не виконано: S5** — зсув звукової доріжки цього конвеєра рендера не
заміряний. Для ролика без кліків у кадр це ~1 кадр і на око не читається,
але формально пункт відкритий.

## Звук і ліцензії

* **Музика:** `house-vibez.mp3` — Lily J, House, 123 BPM.
  Mixkit Stock Music Free License, джерело задокументоване:
  `https://assets.mixkit.co/music/745/745.mp3`
* **Ефекти:** лише файли з **задокументованим посиланням Mixkit**. У наборі
  частина звуків має позначку «джерело невідоме, перед комерційним
  використанням уточнити» (`whoosh-big`, `sparkle`, `riser-cine`, `pop`,
  `keyboard`) — **жоден із них не взятий**.
* 🛑 **Аудіофайли в репозиторій не кладемо.** Репозиторій публічний, а
  ліцензія Mixkit дозволяє використання у проєктах, але не перевидання
  самих файлів. Тому `public/audio/` у `.gitignore`.
  Відтворити: скопіювати з набору video-shotcraft (`assets/audio/`).
* Віддаємо **дві версії**: з музикою і без неї. Без музики — щоб Вова міг
  підкласти трек із бібліотеки самого Facebook.

## Як перезібрати

```bash
cd ad
npm install
# 1. зняти реальні активи сторінки (потрібен локальний сервер сайту)
node scripts/capture.cjs public
# 2. рендер
npx remotion render src/index.ts Ad916 out/tk-ad-9x16.mp4 \
  --browser-executable=/opt/pw-browsers/chromium --codec=h264 --crf=20
```

Правки тривалості — **тільки** в `src/shots.ts`: підписи, звук і склейки
виводяться звідти, інакше доведеться перебивати кадри звуку вручну.
